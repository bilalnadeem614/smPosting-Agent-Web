Privacy Policy

Last updated September 2026

1. Who this covers

smPosting is a personal automation tool with a single owner and operator, Muhammad Bilal Nadeem. It is not a multi-user service. This policy explains how data is handled for the one account that operates it.

2. What data is processed

  • Content the owner submits for posting: video/image files, captions, and scheduling times.
  • Authorization tokens (access and refresh tokens) for the social accounts the owner has connected, including TikTok, obtained through each platform's official OAuth flow.
  • Basic posting status and history (e.g. which platform a post was published to, and when).

TikTok data specifically: Data obtained through the TikTok API (including access tokens and any profile or video information returned by it) is used solely to publish content to the owner's own authorized TikTok account. It is never sold, shared with third parties, used for advertising, or used to build a profile of any user beyond what is required to operate this single connected account.

3. What is not collected

smPosting does not collect data from visitors to this website. There is no analytics tracking, no advertising, and no cookies used for tracking purposes on this site.

4. Storage and security

Authorization tokens and post data are stored in a private, access-controlled automation environment operated by the owner. They are not exposed publicly and are not accessible to any third party.

5. Data retention

Tokens are retained only as long as needed to operate the connected account and are replaced automatically as platforms rotate them. The owner can revoke access at any time directly from the connected platform's own account settings (e.g. TikTok's app permissions page), which immediately invalidates smPosting's access.

6. Third parties

Data is shared only with the platforms the owner explicitly connects (e.g. TikTok, Meta), and only as required to publish the content the owner submitted. No data is sold or shared for any other purpose.

7. Contact

Questions about this policy, or requests to review or delete stored data, can be directed to the owner via the contact details on the home page.
